# Monte Carlo Methods for Semiconductor Electron Dynamics

This project investigates the momentum distribution of an electron trapped near an impurity in an idealized one-dimensional semiconductor.

The numerical study applies Monte Carlo sampling, statistical testing, confidence interval estimation, and variance-reduction techniques.

## Methods

- Acceptance-rejection sampling
- Kolmogorov–Smirnov goodness-of-fit testing
- Monte Carlo estimation
- Importance sampling
- Antithetic variables
- Statistical confidence intervals

## Implementation

The implementation is provided in a Jupyter notebook, covering five parts:

1. Analytical verification of the cumulative distribution function.
2. Sampling and comparison with the theoretical distribution.
3. Estimation of the expected kinetic-energy quantity.
4. Importance sampling for variance reduction.
5. Estimation involving two independent electrons using antithetic variables.

## Technologies

Python, NumPy, SciPy, Matplotlib, Jupyter Notebook
